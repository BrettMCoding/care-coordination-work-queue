# Care Coordination Work Queue

Care Coordination Work Queue is an independent fictional care-team workflow prototype. It is planned as a small full-stack application for exploring how a multidisciplinary team might organize synthetic follow-up work, review recent fictional interactions, and coordinate ownership.

This project uses synthetic data only. It is not a clinical decision-making system and does not provide diagnoses, treatment recommendations, risk scoring, or medical advice.

## Planned Stack

- TypeScript
- React Native
- React Native Web
- Node.js
- MongoDB
- Google Cloud Run

## Project Status

Repository setup is in progress. The application has not been scaffolded or implemented yet.
